# Week 1 Self-Check Quiz

Linear Algebra (501976-001) · Not graded. Answer alone, no notes.
About 10 minutes.

---

**1.** Which equation is linear?

A. `x² + y = 4`
B. `3x - 2y + z = 0`
C. `xy = 10`
D. `sin(x) = 1`

**2.** In the equation `4x - y = 9`, what is the coefficient of `x`?

A. `4`
B. `x`
C. `9`
D. `-1`

**3.** Which of these is **not** one of the three row operations?

A. Swap two equations
B. Scale one equation by a nonzero number
C. Add a multiple of one equation to another
D. Square one equation

**4.** A system of two linear equations, in a graph with two lines,
crosses at exactly one point. How many solutions does the system
have?

A. None
B. Exactly one
C. Infinitely many
D. Cannot tell from a graph

**5.** A system reduces to the equation `0 = 7`. What does this tell
you?

A. The system has a unique solution.
B. The system has infinitely many solutions.
C. The system has no solution.
D. There was a mistake; this cannot happen.

**6.** An augmented matrix is best described as:

A. A new kind of equation, different from a linear equation
B. The same system of equations, written as a grid of numbers
C. A tool used only for systems with no solution
D. A method for guessing the answer faster

**7.** Two equations describe the exact same line when graphed. How
many solutions does the system have?

A. None
B. Exactly one
C. Infinitely many
D. Exactly two

**8. (Short answer)** Solve this system and show your steps:
`x + y = 10`, `x - y = 2`. What are `x` and `y`?

## Answer Key

1. **B.** `3x - 2y + z = 0` — every unknown appears alone, to the first power.
2. **A.** `4` is the coefficient (the known number multiplied by `x`).
3. **D.** Squaring an equation is not a legal row operation; it can create solutions that were not there before.
4. **B.** Two lines crossing at one point means exactly one solution.
5. **C.** `0 = 7` is never true, so the equations contradict each other: no solution.
6. **B.** An augmented matrix carries the same information as the system, just written as a grid.
7. **C.** Identical lines share every point, so there are infinitely many solutions.
8. `x = 6`, `y = 4`. (Add the two equations: `2x = 12`, so `x = 6`; then `y = 10 - 6 = 4`. Check: `6 + 4 = 10` ✓, `6 - 4 = 2` ✓.)
