# Week 10 Self-Check Quiz

Linear Algebra (501976-001) · Not graded. Answer alone, no notes.
About 10 minutes.

---

**1.** Which equation defines an eigenvector `v` of a matrix `A`, for
some number `λ`?

A. `Av = v + λ`
B. `Av = λv`
C. `A + v = λ`
D. `Av = A`

**2.** In `Av = λv`, what is `v = 0` always called?

A. The dominant eigenvalue
B. The characteristic equation
C. The trivial solution
D. The identity matrix

**3.** What must be true of `det(A - λI)` for `λ` to be an eigenvalue
of `A`?

A. It must equal 1
B. It must equal 0
C. It must be negative
D. It must equal the size of `A`

**4.** If `Av = 5v` for some nonzero `v`, what is the eigenvalue?

A. `v`
B. `A`
C. `5`
D. Cannot tell

**5.** Who first named this idea *eigenwert*, German for "own value"?

A. Leonhard Euler
B. Augustin-Louis Cauchy
C. David Hilbert
D. Carl Friedrich Gauss

**6.** PageRank ranks web pages by:

A. Counting the total number of links on each page
B. Finding the one stable "importance" split a link network settles into, repeatedly
C. Picking the page with the newest content
D. Solving a system of linear equations with no repetition at all

**7. (Short answer)** Is `v = (2, -2)` an eigenvector of `A =
[[2,1],[1,2]]`? If so, which eigenvalue? Show your work.
